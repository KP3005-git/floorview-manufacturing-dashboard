# Upwork portfolio entry

## Title
SQL-to-Excel Reporting Automation | C# & .NET

## Role
Developer — AI-assisted portfolio demonstration

## Description
A C# reporting demonstration that generates a formatted Excel workbook from production records. Includes date and shift filters, line summaries, detailed records, rework calculations, and weighted first-pass yield. The exporter validates source data and preserves Excel formulas. Sample-data mode is tested end to end; a parameterized SQL Server connection option is included but requires database testing. Uses synthetic data.
